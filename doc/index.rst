#####################
jira-issues-dashboard
#####################

``jira-issues-dashboard`` is a Streamlit application for Jira issue triage and
operational awareness. It was developed for Rubin Observatory Observing
Operations workflows and is packaged as a uv-first Python project.

The application provides dashboard views for issue activity, stale tickets,
personal workload, and operational groupings such as OBS system, subsystem, and
component when those fields are available in Jira.
